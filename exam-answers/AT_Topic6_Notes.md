## 一、企业在单中心城市模型中的Bid-Rent

### 1.1 企业为何集中在CBD？

**历史上**：
- 需要靠近天然港口（贸易城市）
- 在市场上销售商品（Von Thünen）
- 运输成本下降后，这些理由减弱

**今天**：
- 集聚力随距离衰减（agglomeration spillovers declining with distance）
- 知识溢出极为局部：在CBD集聚更合理
- 劳动力池集中（位于劳动力中心）

### 1.2 企业Bid-Rent推导

**生产函数**（Cobb-Douglas）：χᵢ = Aᵢ · Kᵢᵅ · Lᵢ¹⁻ᵅ

**生产率溢出**：Aᵢ = a·e^(-θDᵢ)（随距CBD距离Dᵢ指数衰减）
- θ > 0：衰减速度（θ越大，溢出越局部）

**零利润条件**（完全竞争）：

π = χᵢ - Kᵢ - ψᵢLᵢ = 0

→ 地租ψᵢ = C·e^(-θDᵢ/(1-α))

→ **∂ψᵢ/∂Dᵢ < 0**：企业bid-rent随距CBD距离下降

```
企业bid-rent曲线（大θ，陡峭）：

地租ψ
    |●  ← CBD中心
    |  ●
    |    ●
    |      ●
    |        ●________
    |_________________
    0          距CBD距离D

θ大 → 集聚溢出快速衰减 → 陡峭的bid-rent（企业强烈倾向CBD）
θ小 → 溢出衰减缓慢 → 平坦（企业愿意分散）
```

## 二、土地用途分离

### 2.1 各用途Bid-Rent曲线对比

```
地租/价格
    |\
    | \  ← r_com（商业，最陡）
    |  \
    |   ● x₁
    |    \  ← r_res（住宅，中等斜率）
    |     \
    |      ● x₂
    |       \  ← r_man（制造业，最平）
    |        \
r_A |—————————●——————  农业地租r_A（常数）
    0      x₁  x₂  x₃     距CBD距离
                    ↑
                 城市边界

    0→x₁：商业（r_com最高）
    x₁→x₂：住宅（r_res最高）
    x₂→x₃：制造业（r_man最高）
    x₃以外：农业
```

**土地归出价最高者**：在任意距离x，该距离的土地用途由出价最高的部门决定。

**每条bid-rent曲线是凸的**（由于c和q之间的替代效应）。

**整体地价梯度更加凸**：不同部门在不同区位的分类（sorting）使梯度更陡。

### 2.2 CBD主导的是什么行业？

**Ahlfeldt et al. (2020)**：
- CBD由**优质服务业**主导（金融、保险、房地产、专业服务）
- 基于知识的可贸易服务业高度集中在CBD
- 制造业就业更加分散
- 位置自然禀赋对优质服务业不一定重要（不需要港口）

## 三、集聚与去中心化

### 3.1 内生集聚力与多重均衡

**简单模型的局限**：假设集聚从CBD向外单向扩散——强假设。

**更现实的模型（Ahlfeldt & Wendland 2013）**：
企业彼此之间都产生溢出（bilateral spillovers）：

Aᵢ = aᵢ·e^(-θDᵢ) · e^(βZᵢ)，其中Zᵢ = Σⱼ χⱼ·e^(-τdᵢⱼ)

→ 企业i的生产率取决于附近所有企业j的产出（双向集聚力）

### 3.2 城市结构含义

**强CBD溢出**（大θ）：
```
初始冲击（某些企业迁至郊区）
    ↓
CBD外生拉力强 → 企业被拉回CBD
    ↓
城市结构稳定（单一均衡）
```

**双向集聚力**（内生集聚）：
```
初始冲击（某些企业迁至郊区）
    ↓
郊区集群产生自己的集聚经济
    ↓
城市结构改变 → 多重均衡！
    ↓
结果取决于历史偶然（类似Krugman 1991）
```

### 3.3 柏林历史案例（Ahlfeldt & Wendland 2013）

- **1890-1940年**：历史CBD对企业吸引力极强（集聚+便利设施高度集中）
- **初期**：双向集聚力（企业间溢出）作用有限，CBD效应主导
- **随时间推移**：去中心化集聚力重要性↑，直接CBD效应↓
  - 原因：经济向知识密集型服务业转型

**实证证据**：
- 今天可贸易服务业高度集中在CBD（低θ不足以让其分散）
- 制造业大规模去中心化（低溢出→可分散）

### 3.4 就业去中心化的驱动因素（Glaeser & Kahn 2001）

美国城市大多已去中心化：
- 距CBD 3英里内就业份额 < 29%（NYC是例外）
- 1950年代以来中心区就业份额持续下降

**去中心化的原因**：
1. 运输技术变革（制造业）
2. 人口郊区化（就业跟随人口）
3. 财政和社会问题（贫困、犯罪）
4. 老龄化建筑存量
5. 规定（高度限制、土地使用）

**中国证据（Baum-Snow et al. 2017）**：
| 基础设施类型 | 去中心化效应 |
|-------------|-------------|
| 放射状公路 | 去中心化服务业就业 |
| 放射状铁路 | 去中心化20%工业就业 |
| 环形道路 | 去中心化两者（50%工业） |
| 放射/环形道路 | 置换4%/20%市中心人口 |

## 四、次级中心与边缘城市

### 4.1 次级中心（Sub-centers）— 内生形成

**Fujita & Ogawa (1982)** 预测：
- 次级中心数量随**人口**增加而增加
- 次级中心数量随**通勤成本**增加而增加
- 次级中心是内生涌现以保持城市效率的

**McMillen & Smith (2003) 实证检验**：
- 识别方法：找出就业密度的局部峰值（超过预测值的位置）
- 结论：
  - 人口↑ + 拥堵↑ → 次级中心数量迅速增加
  - 老龄化住房存量的城市次级中心更多

```
就业密度
    |   CBD峰值
    |  ●
    | ● ●
    |●   ●       次级中心峰值
    |      ●    ●
    |       ● ●● ●●●●●________
    |___________________________
    0            距CBD距离

识别次级中心：实际密度 - 仅由距离预测的密度 > 显著阈值
```

### 4.2 边缘城市（Edge Cities）— 由单一开发商建造

**定义特征**（Garreau 1991）：
- 由单一开发商在城市边缘建造
- 容纳知识密集型可贸易服务
- 以A级写字楼为主（高质量办公空间）
- **净通勤目的地**（不同于住宅郊区）：就业多于卧室
- 完整城市功能（就业+休闲+娱乐）

**vs. 次级中心**：
| | 次级中心 | 边缘城市 |
|---|---|---|
| 形成方式 | 内生、分散决策 | 单一开发商战略决策 |
| 目的 | 效率 | 利润最大化 |
| 例子 | 各城市自然形成的就业集群 | Canary Wharf（伦敦）、La Défense（巴黎） |

**开发商为何建边缘城市**？
- 内化集聚溢出（最大化生产率→地价）
- 规避社会和财政问题（贫困、犯罪）
- 减少容量约束（拥堵）
- 解决集聚固有的协调问题：
  - 开发前地价低 → 开发后地价高 → 利润！

**Henderson & Mitra (1996) — 开发商优化**：
- 开发商选择边缘城市的容量K和距港口城市（CBD）的距离
- **Trade-off**：越靠近CBD
  - 好处：从CBD获得更大溢出→生产率↑
  - 坏处：地价↑、工资补偿要求↑

**关键结果**：CBD容量K₀的小变化可以触发边缘城市位置的大变化（非线性！）

**原型案例：Tyson's Corner**（美国弗吉尼亚州）：
- 东海岸NY以南最大零售区
- 28百万平方英尺A级写字楼（vs 华盛顿DC市中心17百万）
- 3400间酒店客房，100,000+工作岗位

### 4.3 历史锚定（Historic Anchoring）

**问题**：为什么某些城市没有去中心化？（例：NYC vs LA）

**解释**：
- NYC 1900年人口340万；LA 1900年人口只有10万
- NYC更早建立了更大的交通系统
- 早期交通投资（地铁/铁路）→ 强化城市核心位置优势 → 后续就业更不可能迁移

**Ahlfeldt et al. (2020)** 发现：
- 1900年人口更大的城市更可能发展出综合交通系统（朝向城市核心）
- 交通系统强化定位优势 → 优质服务业更可能"锚定"在历史CBD附近
- 解释美国东西海岸、美国vs欧洲/亚洲城市结构差异
