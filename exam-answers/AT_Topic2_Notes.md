## 一、集聚的测量

### 1.1 核心测量指标

| 指标 | 测量什么 | 公式 |
|------|----------|------|
| 就业份额分布 xᵢ | 空间就业分布是否均匀 | ∑xᵢ² |
| HHI (H) | 行业企业集中度 | H ≡ ∑ᵢ sᵢ² |
| Gini系数 (G) | 行业区域分布与整体的差异 | G ≡ ∑ᵢ(xᵢ - sᵢ)² |
| **EG指数 (γ)** | 相对随机位置的超额集中度 | 见下 |

### 1.2 Ellison-Glaeser (1997) 指数 (EG Index)

**最重要的测量工具！**

含义：
- **γ = 0**：行业的空间集中度与随机位置过程一致（无额外集聚）
- **γ > 0**：存在超额空间集中（集聚）
- **注意**：高EG指数不能证明存在集聚外部性——只测量集中度，不能识别原因

**所有测量指标的共同问题**：需要先定义"市场/地理范围"（多近算近）

## 二、哪些行业集聚？（Rosenthal & Strange, 2001）

**核心发现**：
- 所有行业EG指数均为正（都有某种集中）
- 集中度在**州级（state）层面最高**

### 2.1 集聚的五大来源

| 来源 | 代理变量 | 空间层级 |
|------|----------|----------|
| 知识溢出 | 新产品数/每$货运量 | 地方（zip code） |
| 劳动力市场汇聚 | 生产率/工人、管理比例、高技能比例 | 所有层级 |
| 投入共享 | 制造投入/每$货运量 | 区域（state） |
| 自然禀赋 | 能源支出/每$货运量 | 区域（state） |
| 运输成本 | 库存/每$货运量（低库存=易腐/笨重货物） | 区域（state） |

### 2.2 Rosenthal & Strange (2001) 主要结论

```
决定因素        | Zip Code | County | State
-------------- | -------- | ------ | -----
自然禀赋        |    ✗     |   ✗    |  ✓
运输成本        |    ✗     |   ✗    |  ✓
投入共享        |    ✗     |   ✗    |  ✓
劳动力市场汇聚  |    ✓     |   ✓    |  ✓  ← 全尺度有效！
知识溢出        |    ✓     |   ✗    |  ✗  ← 只在本地！
```

**关键洞见**：
- 知识溢出作用范围极小（街区/建筑级别）
- 劳动力市场效应在整个通勤区有效
- 自然禀赋和运输成本在区域层面重要

## 三、集聚效应的空间尺度

### 3.1 核心问题："How close is close?"（Rosenthal & Strange, 2020）

集聚效应甚至在**建筑和组织**内部就能起作用——比人们想象的更局部。

**为什么距离如此重要**？
1. 单一集聚效应：溢出随距离指数衰减
2. 不同机制作用于不同空间层次（知识溢出<劳动力汇聚）
3. 异质互动成本：距离影响不同个体利用远程交互的能力

```
集聚效应强度 vs 距离

强度
  |█
  |█
  |██
  |███
  | ████
  |   ██████
  |         ████████████████
  |_________________________________
  建筑  街区  邻里  通勤区  大都市区    距离
  ←知识溢出→←劳动力汇聚→
```

### 3.2 不同机制的空间范围

- **知识溢出**：极度局部，街区甚至楼层内
  - Arzaghi & Henderson (2008)：Madison Avenue广告业知识溢出
  - Rosenthal & Strange (2008)：人力资本溢出的急剧衰减
- **劳动力市场汇聚**：在通勤区内有效（大都市区定义就基于通勤流）

## 四、集聚对生产率的效应

### 4.1 城市层面估计（有选择性偏差！）

**Ciccone & Hall (1996)**：
- 密度弹性 γ ≈ **0.04-0.07**
- 解读：密度翻倍 → 生产率提升约 **4%**（= 2^0.06 - 1）
- **问题**：高能力工人向大城市选择性迁移（sorting）

```
问题：因果方向不清
  城市大/密度高 ────→ 工资高？
       ↑              
  高能力工人选择迁入大城市也会提高城市工资
```

### 4.2 个人层面估计（控制选择性）

加入**个人固定效应**（individual fixed effects）：
- 识别来自"迁移者"：同一个人在不同城市的工资比较
- 控制不可观察个人特征后，弹性降至 γ ≈ **0.02**
- **更接近因果估计**（"纯"密度效应）

### 4.3 IV估计（控制位置效应）

**问题**：位置不可观察特征（unobserved location effects）

**解决方案**：工具变量（IV）
- Ciccone & Hall (1996)使用历史工具：
  - 1860年铁路存在
  - 1850和1880年州人口
  - 距东海岸距离

**面板数据方法**：
- Ahlfeldt & Feddersen (2018)：高铁开通作为外生冲击，发现 γ = **2-3%**

### 4.4 关键数字对比

```
估计方法              | 弹性γ  | 问题/特点
--------------------|-------|------------------
城市层面OLS           | 0.04-0.07 | 有sorting偏差，相关性
个人层面（固定效应）    | ~0.02  | 更接近因果
面板IV（高铁/历史）    | 0.02-0.03 | 更干净的因果

→ 密度翻倍：生产率提升约2-4%
```

## 五、城市化 vs 本地化经济

### 5.1 理论对比

| 学派 | 代表人物 | 核心论点 | 政策建议 |
|------|----------|----------|----------|
| **MAR** | Marshall-Arrow-Romer | 同行业专业化 → 创新 | 支持本地垄断（内化外部性） |
| **Porter** | Porter (1990) | 专业化+竞争 | 鼓励本地竞争性专业化行业 |
| **Jacobs** | Jacobs (1969) | 跨行业多样性 → 创新 | 鼓励多元产业多样性 |

### 5.2 主要实证研究结论

**Henderson (1988)**：
- 回归：行业城市产出/工人 ~ 同行业城市总产出(本地化) + 城市总人口(城市化)
- **本地化系数显著（0.02-0.11随行业变化）**
- 城市化系数接近零
- → **本地化经济对生产率水平重要**

**Glaeser et al. (1992)**：
- 回归：1956-1987城市-行业就业增长率 ~ 专业化程度 + 竞争程度
- 竞争对增长有利 ✓
- 专业化对增长有负效应 ✗
- → **支持Porter & Jacobs，不支持MAR**

**Henderson et al. (1995)**：
- 分成熟产业 vs 高科技产业分析
- **成熟产业**（机械、钢铁、运输）→ 支持MAR（本地化）
- **高科技产业**（电子元件、医疗设备、计算机）→ 支持MAR + Jacobs（本地化+城市化均重要）

**Duranton & Puga (2001) — "育儿城市"理论**：
```
产品生命周期与城市类型：

新产品开发阶段 → 多元城市 (diversified city)
  ↓ 找到最佳生产流程
批量生产阶段 → 专业化城市 (specialized city)（成本更低）

证据：72%的迁移从多元→专业化城市
     高科技行业更明显（R&D 93%, 制药 88%, IT 82%）
```

### 5.3 综合结论

```
经济指标        | 本地化（MAR）| 城市化（Jacobs）
--------------|-----------|---------------
生产率水平      |    ✓✓     |      ~
生产率增长      |    ✓      |      ✓✓
成熟产业       |    ✓✓     |      ~
高科技产业     |    ✓      |      ✓✓
```

**关键规律**：小型专业化城市生产率高（工资高），但大型多元化城市更具动态性（更快增长）。

## 六、对房地产市场的影响

1. **集聚效应被资本化进租金**：知识溢出和劳动力汇聚使某些位置比其他更有价值
2. **商业地产**：靠近其他同行业企业的位置溢价（尤其金融、法律、科技）
3. **交通网络设计**：集聚经济的空间范围影响最优通勤系统设计

## 七、考试要点

### 核心数字（必背！）

| 数字 | 含义 |
|------|------|
| **γ = 0.04-0.07** | 城市层面密度弹性（OLS，有偏） |
| **γ ≈ 0.02** | 个人层面密度弹性（固定效应，更因果） |
| **密度翻倍 → ~4%** | 生产率提升（城市层面） |
| **密度翻倍 → ~2%** | 生产率提升（个人层面，更可信） |
| **72%** | Duranton & Puga：多元→专业化的迁移比例 |

### EG指数的局限性

高γ值说明集中，但不能识别：
1. 是自然禀赋（煤炭/港口）引起的？
2. 是MAR型知识溢出？
3. 是劳动力汇聚？
4. 是纯历史偶然？

→ 需要回归分析分解

### 可能的考题方向

**Essay型**：
- "Discuss the empirical evidence on agglomeration economies. What do we know about their magnitude and spatial scale?"
- 答题框架：测量问题（EG指数）→ 识别挑战（sorting/IV）→ 估计结果（0.04 vs 0.02）→ 空间范围（知识溢出局部，劳动力市场更大）→ 城市化vs本地化

**Partitioned型**：
- (a) 解释城市层面和个人层面估计的差异，为什么个人层面更接近因果？
- (b) 什么是"nursery cities"假说？有什么证据支持？
- (c) 劳动力市场汇聚和知识溢出在空间范围上有何不同？

### Krugman vs Marshall vs 实证对比

| | Krugman | Marshall | 实证（Combes等） |
|---|---|---|---|
| 规模类型 | 内部规模收益 | 外部规模收益 | 外部（通过密度代理） |
| 关键成本 | 货物运输 | 人员通勤 | 密度（距离） |
| 弹性估计 | 定性 | 定性 | 0.02-0.06 |
