## 一、英国供给约束的类型

### 1.1 监管性约束（Regulatory Constraints）

**代理变量**：主要住宅项目的拒绝率（1979-2008年）

其他监管约束：
- 绿化带（Green Belts）
- 高度限制（Height Restrictions）
- 保护区（Conservation Areas）

### 1.2 物理性约束（Physical Constraints）

**代理变量**：可开发空地的比例、坡度、海拔变化范围

```
供给约束
    ├── 监管性：规划拒绝率、绿化带、高度限制
    └── 物理性：可开发土地少（水体、山地、已建成区域）
```

## 二、内生性问题与IV策略

### 2.1 为什么直接OLS有偏？

**核心问题**：高房价地区（如伦敦）可能：
1. 有更严格的规划限制（因为地价高→更多利益相关者反对新建）
2. **同时**因为高生产率/就业→高工资→高需求

→ OLS无法分开供给约束的效应和需求效应

**同时，规划拒绝率本身可能内生**：
- 高度紧张的市场 → 当局批准更多 OR 拒绝更多（取决于政治）
- 需要外生变化来源

### 2.2 IV策略（关键！）

**Hilber & Vermeulen (2016)使用的工具变量**：

| 工具变量 | 类型 | 排他性理由 |
|----------|------|------------|
| 延迟利率改革 | 监管约束的IV | 改革时间与局部需求无关 |
| 地方工党投票份额 | 监管约束的IV | 政治偏好不直接影响需求 |
| 1911年历史密度 | 物理约束的IV | 历史开发→现存建成区→物理约束 |
| 劳动需求冲击（Bartik） | 需求的IV | 行业构成×全国趋势，与供给无关 |

## 三、主要实证结果

### 3.1 核心研究设计

**因变量**：log（房价）

**关键变量**：log（收入） × 各种供给约束

**思路**：
- 若供给约束不重要：收入↑对各地房价影响相同
- 若供给约束重要：收入↑在约束严格地区引起更大价格上涨

### 3.2 OLS（有偏）vs IV（较干净）估计

| 变量 | OLS估计 | IV估计 | 含义 |
|------|---------|--------|------|
| log(收入) | 0.32 | 0.089 | OLS高估（sorting效应） |
| log(收入) × 拒绝率 | 0.067 | **0.29\*\*\*** | 法规约束关键！ |
| log(收入) × 已开发份额 | 0.094 | **0.30\*\*\*** | 物理约束同样关键！ |
| log(收入) × 海拔变化 | — | **0.095** | 地形约束也重要 |

**解读**：
- 在规划拒绝率高的地区，收入上升引起的房价涨幅**高29%**
- 在已高度开发（土地少）的地区，收入上升引起的房价涨幅**高30%**

```
拒绝率高 + 收入↑ = 房价涨幅↑29%（相比拒绝率低地区）

                Westminster（伦敦）  vs  Newcastle
规划限制：          极严格               宽松
物理限制：          极受限               适中
供给约束效应：       巨大                微小
→ 相同需求冲击：    价格大幅上涨         价格微幅上涨
```

## 四、反事实分析（Counterfactual）— 英格兰

**问题**：如果规划限制放松，会发生什么？

### 4.1 主要反事实结果

| 情景 | 房价变化 |
|------|----------|
| 平均LPA（地方规划当局）放松规划 | **-35%** |
| 土地丰富 + 规划放松 | **-45%** |
| 地形完全平坦 | **-48%** |

**即：英格兰的供给约束使房价比理论水平高约35-48%！**

### 4.2 城市差异

```
威斯敏斯特（伦敦中心）：
  供给约束极强 → 自1974年以来价格溢价持续且巨大

纽卡斯尔：
  供给约束弱 → 价格受供给约束影响很小
```

## 五、信贷条件的作用

### 5.1 Favara & Imbs (2015) — 美国银行分支管制解除

**自然实验**：1994-2005年美国分阶段的银行跨州分支管制解除

**发现**：
- 信贷供给扩张解释了**50-67%**的抵押贷款增加
- 解释了**33-50%**的房价上涨
- **重要**：信贷扩张在供给弹性地区对房价影响**更小**（数量调整）

**含义**：
```
信贷宽松 + 供给非弹性（如伦敦）：
  → 需求↑↑ → 价格大幅↑（供给无法响应）

信贷宽松 + 供给弹性（如休斯顿）：
  → 需求↑↑ → 新建↑↑ → 价格小幅↑
```

**信贷条件和供给约束共同放大周期**！

### Hilber & Vermeulen 模型框架速查

```
研究问题：供给约束（法规+物理）如何放大外生需求冲击对房价的影响？

识别：OLS有偏（内生性） → IV/2SLS
  供给约束的IV：政治变量、历史密度
  需求的IV：Bartik劳动需求冲击

核心结果：
  拒绝率高地区，收入1%↑ → 房价多涨0.29%（相比拒绝率低地区）
  已开发份额高地区，收入1%↑ → 房价多涨0.30%

政策含义：供给约束是英国房价高的主要原因（约35-48%溢价）
```
