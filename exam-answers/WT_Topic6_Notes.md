## 一、六大竞争理论

### 1.1 理论1：近视代理人与时滞（Cobweb模型）

**机制**：
- 开发商/贷款人基于**当前/历史价格**做决策（而非预期价格）
- 建设有时间差（2-3年从决策到完工）
- → 在价格信号到建设响应之间存在时滞
- → 产生振荡（价格波动传导到供给，再传导回价格）

**Cobweb图解**：

```
价格P
    | S（供给）
    |         D（需求）
P2  |   ●←←←←→→→→
    |   ↑↓      ●P1
    |   ●→→→→→←←←
P1  |          ●
    |_______________________
    Q2   Q1    数量Q

→ 开发商以价格P1时开始建设
→ 建设完成时（时滞后），大量新供给→价格跌至P2
→ 价格P2时减少建设
→ 下一轮：稀缺→价格↑到P1...循环
```

**何时最严重**：
- 供给弹性**大**（开发商能快速响应）
- 建设时滞**长**
- 典型案例：**休斯顿1980年代**（无区划/弹性供给 + 石油冲击→严重过度建设然后崩溃）

### 1.2 理论2：非理性繁荣（Herding/Irrational Exuberance）

**机制**：
- 代理人使用**向后看的预期**（extrapolating recent trends）
- 价格上涨→预期继续上涨→需求增加→价格进一步上涨→泡沫
- 情绪化需求、羊群效应

**Capozza et al. (2004) 发现**：
- 繁荣市场中序列相关性更强
- 即：价格上涨时，趋势延续的趋势更强

**问题**：
- 难以证伪（无法与"模型误设"区分）
- 如何界定"理性"预期？

### 1.3 理论3：流动性约束

**机制**：
- 收入冲击→影响首次购房者的能力
- 杠杆买家（如高LTV抵押贷款）价格敏感度更高
- 流动性约束影响向上置换市场（trade-up market）

**Lamont & Stein (1999)**：
- 更多杠杆房主（高LTV比）→ 更强的价格敏感性
- 高LTV比例↑ → 随后价格波动↑

**Genesove & Mayer (1997)**：
- 高LTV卖家：要价更高，也卖出更高的价格
- → 流动性约束扭曲了市场定价行为

### 1.4 理论4：损失厌恶（Loss Aversion — Kahneman-Tversky框架）

**行为经济学基础**：
- 损失的心理痛苦 > 同等收益的心理快乐
- 效用函数在损失域中凹陷更陡

**对房地产的应用**：

**Genesove & Mayer (2001 — QJE重要文献)**：

研究设置：波士顿房地产市场1990年代初萧条

**核心发现**：
- 面临**账面损失**的卖家（购买价>当前市价）：
  - 要价比不面临损失的卖家**高3-18%**
  - 最终成交价**高3-7%**（不完全放弃，但有效果）
  - 在市场上停留**更长时间**（time-on-market更长）
- 效果在高LTV（下行更多）时**更强**

```
正常情况（无损失厌恶）：
  市价下跌 → 卖家接受更低价 → 市场出清

损失厌恶：
  市价下跌 → 卖家要价高于市价 → 等待
  结果：交易量↓（market freeze），价格粘性（downward sticky）
```

**对市场的影响**：
- 萧条期交易量大幅下降
- 价格不够灵活（不能迅速调整到均衡）
- 导致市场流动性危机，延长萧条

### 1.5 理论5：期权价值理论（Option Value — Grenadier 1995）

**核心洞见**：建设决策是**可撤销的期权**

- 现在建设：放弃等待权利
- 等待：保留在更好时机建设的期权

**需求波动↑ → 等待期权价值↑ → 建设推迟**

**结果**：
- 在高度波动的市场（如商业地产），开发商**理性地**等待，即使现有空置率高
- 解释了为什么商业地产市场在萧条时期也可能出现"过剩容量是理性的"

**对空置率的解释**：
- 在需求高度不确定时，高空置率不一定是市场失灵
- 而是开发商保留"改变心意"的期权

### 1.6 理论6：搜索与匹配（Search & Matching — Head et al. 2014）

**机制**：
- 住房是**异质商品**（每套不同）
- 信息搜索成本高
- 需求冲击→买家搜索→价格发现需要时间→时间序列中价格滞后调整

**模型结果**：
- 收入冲击→买家开始搜索
- 供给响应有时滞→价格先上涨
- 最终建设跟上→空置率调整→价格稳定

## 二、价格/租金比率（P/R Ratio）谜题

### 2.1 典型事实

**日本**：泡沫破裂后，价格崩溃但租金保持稳定
→ P/R比率急剧下降

**伦敦 vs 英格兰北部**：P/R比率巨大空间差异且有周期性变化

### 2.2 Hilber & Mense (2026) 模型解释

**模型机制**：
- 短期和长期供给约束 + 需求冲击自相关（autocorrelated）
- → P/R比率周期性波动

**三个模型预测**：
1. 非弹性供给 + 需求冲击序列相关 → P/R比率周期性升高
2. 效应在非弹性（superstar）城市更强
3. 实证证据支持所有三个预测

**模型解释能力**：
- 解释伦敦 vs 英格兰东北部P/R差异的**67-100%**

## 三、商业 vs 住宅周期对比

| 维度 | 商业地产 | 住宅地产 |
|------|---------|---------|
| 价格波动 | 更大 | 相对小 |
| 周期类型 | 往往是内生驱动 | 外生需求驱动为主 |
| 与经济的关联 | 弱（商业周期与GDP不同步） | 较强 |
| 主要驱动力 | 投资/融资决策 | 居住需求 |
| 期权效应 | 强（建设可以推迟） | 中等 |

---

## 四、理论整合：何时哪种机制主导？

```
外生需求冲击 + 弹性供给 → Cobweb（建设过度）
外生需求冲击 + 非弹性供给 → H&V: 价格泡沫（Topic 5）
内生驱动 + 行为偏差 → 损失厌恶（价格粘性/交易量↓）
内生驱动 + 商业地产 → 期权效应（理性过剩容量）
```
