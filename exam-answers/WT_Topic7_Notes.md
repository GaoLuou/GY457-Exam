## 一、典型事实：住房自有率

### 1.1 跨国差异

| 国家 | 住房自有率 | 特点 |
|------|----------|------|
| 西班牙 | **81.5%** | 低收入，高自有率 |
| 瑞士 | **37.2%** | 高收入，低自有率 |
| 英国 | 65%（2021） | 从峰值69.5%（2001-02）下降 |

**"悖论"**：
- 国家内部：收入↑ → 更可能自有（正相关）
- 跨国比较：更富裕的国家 → 更低自有率（负相关！）

**解释悖论**：
- 富国有更发达的租房市场（租房不再是"没有选择"）
- 富国的住房价格相对于收入可能更高（影响可及性）
- 文化/机构差异（德国、瑞士租房文化）

### 1.2 英国历史趋势

```
英国住房自有率：
1945-50: 29%（战后起点）
  ↓ 逐步上升（右购政策等）
2001-02: 69.5%（历史峰值）
  ↓ 下降（高P/R比、首付约束）
2021: 65%

年轻群体自有率持续下降：
  原因：高P/R比 + 首付约束
  Help-to-Buy (2013+)效果有限
```

## 二、住房自有的社会收益

### 2.1 主要正外部性

| 效益类型 | 机制 | 证据 |
|----------|------|------|
| **房屋维护** | 租自己的房子→避免道德风险，更好维护 | 理论上清晰 |
| **社会资本** | 房主在社区长期投资→支持本地学校、减少犯罪 | 主要在城市化地区 |
| **政治参与** | 房主更积极参与本地政治 | 保护资产价值动机 |
| **儿童发展** | 更好的育儿环境，稳定居住 | 存在争议 |
| **退休储蓄** | 自动强制储蓄→减少退休贫困 | 与养老金体系替代关系 |

**注意**：这些收益主要在**城市化程度较高**的地区（农村地区租房文化可能不同）

## 三、住房自有的社会成本

### 3.1 主要负外部性

**流动性降低 → 失业**：

**Oswald (1996) 假说**：自有率高的地区失业率更高（流动性假说）
- 机制：房主在劳动力市场冲击后搬家成本高 → 宁愿失业也不迁移
- 后续研究发现证据混合，但方向支持

**Munch et al. (2006)**（丹麦数据）：
- 房主：更可能在本地找工作，但工作持续时间更长
- 租户：更愿意长距离通勤或搬迁找工作

**抑制创业**：

**Bracke et al. (2018)**：
- 杠杆化住房自有**大幅减少**创业
- 机制：房主已将大量财富集中在房产→风险承受能力↓
- "把所有鸡蛋放在一个篮子（房子）里"

**NIMBY行为**：
- 房主 = 比租户更倾向于反对新住房开发
- 保护资产价值的动机使房主成为规划限制的政治支持者
- 加剧供给约束（自我强化的循环）

## 四、住房自有补贴的有效性 — 最重要结论！

### 4.1 主要补贴形式

| 政策 | 国家 | 形式 |
|------|------|------|
| 抵押贷款利息扣除 (MID) | 美国 | 利息从税前收入中扣除 |
| Help-to-Buy | 英国 | 首付补贴/政府贷款 |
| 印花税豁免 | 多个欧洲国家 | 首次购房豁免交易税 |

### 4.2 核心研究结果（关键！）

**Hilber & Turner (2014) — 美国MID政策评估**：

**核心发现**（非常重要，考试高频！）：

| 供给弹性 | 补贴效果 |
|----------|----------|
| **非弹性供给市场**（如旧金山、纽约） | **负效应（！）**：补贴降低了住房自有率 |
| 弹性供给市场（如休斯顿、凤凰城） | **正效应**：补贴提高了住房自有率 |
| **全国平均** | **基本零效应**：补贴无效 |

**为什么非弹性市场补贴有负效应？**

```
非弹性供给市场：
  补贴 → 首次购房者能负担更多 → 需求↑
    ↓（供给无法增加）
  价格↑↑（所有价格上涨，不只新建）
    ↓
  首付要求↑（价格×%首付）
    ↓
  首次购房更难（抵消补贴！）
  富裕购房者获益，中产首次购房者净受损
  
→ 补贴资本化进价格，惠及现有房主（不是补贴对象！）
```

**Sommer & Sullivan (2018)**（模拟美国MID取消）：
- 取消MID：住房自有率几乎不变（证实补贴基本无效）

**欧洲证据**（西班牙、意大利税改）：
- 约**2%**的住房自有率提升（小正效应，但成本高）

**美国MID政策效率**：
- 每年税收损失：**250-600亿美元**
- 住房自有率提升：基本为零

### 4.3 福利经济学评价

```
补贴是否值得？需要满足：补贴收益（外部性） > 补贴成本

问题1：正外部性主要在非弹性供给地区（城市化地区）
问题2：在非弹性供给地区，补贴实际降低自有率（无益！）
问题3：负外部性（NIMBYism）可能抵消正外部性

结论：住房自有补贴 = 无效政策；在非弹性市场甚至适得其反
```

## 五、住房自有率的决定因素

### 5.1 关键发现（Hilber & Mense 2026）

**住房存量构成是最重要的决定因素！**

**关键数字**：多单元住宅（公寓）比例增加10个百分点 → 自有率下降约8个百分点

为什么？
- 公寓天然适合租房（房东规模效应、分割产权）
- 房东拥有和管理公寓的效率高于单套公寓的所有者

```
决定因素排序：
1. 住房存量构成（多单元 vs 独栋）←最重要
2. 公共/社会住房比例（负效应）
3. 税收政策（弱效应）
4. P/R比率（首付约束：P/R高→更难自有）
```

## 六、考试要点

### 核心数字（必背！）

| 数字 | 来源 | 含义 |
|------|------|------|
| **81.5% vs 37.2%** | 西班牙 vs 瑞士 | 住房自有率跨国差异 |
| **69.5% → 65%** | 英国 | 2001年峰值到2021年下降 |
| **零效应（全国）** | Hilber & Turner (2014) | MID对住房自有率的平均效果 |
| **负效应** | Hilber & Turner (2014) | MID在非弹性市场对住房自有率的效果 |
| **$250-600亿** | 美国MID | 每年税收损失 |
| **2%** | 欧洲改革 | 住房补贴的最大正效应 |
| **8个百分点** | Hilber & Mense (2026) | 公寓比例增加10pp→自有率下降幅度 |

### "补贴无效"逻辑速查

```
补贴 → 需求↑ → 
  弹性供给：数量↑，价格微涨 → 自有率↑（有效！）
  非弹性供给：价格大涨，数量不变 → 首付要求↑ → 自有率↓（适得其反！）
  
全国平均：弹性和非弹性效应相互抵消 → 基本零效果
```
