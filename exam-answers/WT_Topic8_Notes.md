## 一、典型事实

### 1.1 城镇化

- 1950年：城镇化率极低
- 2024年：城镇化率**67%**（放缓中）
- 速度之快是历史上绝无仅有的

### 1.2 住房价格上涨

**2003-2018年，35个主要城市**：
- 名义价格上涨：**313%**（年均 **+8%**）
- 实际价格上涨：**178%**（年均 **+4%**）
- 一线城市（北京、上海、广州、深圳）涨幅更高

**对比**：与旧金山、伦敦等超级城市在**绝对USD/m²**水平上相当

### 1.3 近期降温

- **名义房价从Q3 2021至2025下跌24%；实际下跌27%**
- 三线城市大幅下跌；一二线城市趋于平稳
- 疫情后市场大幅调整

### 1.4 关键比率（极端！）

**价格/收入比（P/I Ratio）**：

| 城市 | P/I比 |
|------|-------|
| **深圳** | **31.8** |
| **北京** | **21** |
| **上海** | **18.2** |
| **旧金山** | 8.8 |
| **伦敦** | 8.3 |

**价格/租金比（P/R Ratio）**：

| 城市 | P/R比 | 隐含资本化率 |
|------|-------|-------------|
| **北京** | **50** | 2% |
| **上海** | **45** | 2.2% |
| 伦敦 | ~31 | — |
| 纽约 | ~27 | — |

**这意味着买套北京公寓出租，50年才能收回成本（仅租金，不计增值）**

## 二、四大假说

### 2.1 假说一：非理性繁荣（Irrational Exuberance）

**证据**：P/R = 50（北京）= 资本化率2%

**如何判断是否合理**？用Gordon增长模型：

**资产定价公式**：P = R / (r - g)

其中：
- P = 价格
- R = 租金
- r = 贴现率
- g = 预期租金增长率

如果 g = 4%（与历史GDP增长相符），则 r = 4% + 2% = 6%（这对房地产来说并不罕见）

**结论**：
- 历史GDP增长6.5%（疫情前）→ P/R 50可能不完全是泡沫
- 但目前GDP增长放缓至3-5.4% → 估值可能偏高
- 不是纯泡沫，但存在拉伸

### 2.2 假说二：供给约束（最有力的解释！）

**事实**：一线城市土地供给更少，尽管需求更高（反常！）

**一线城市 vs 全国平均FAR（容积率）限制**：
| 城市 | FAR上限 |
|------|---------|
| 上海 | 1.9 |
| 北京 | 2.3 |
| **全国平均** | **2.8** |

即：需求最旺的城市反而建得最矮！

**为什么供给受限（五大原因）**：

| 原因 | 机制 |
|------|------|
| 1. 耕地红线政策 | 18亿亩耕地保护线 → 不得转为城市建设用地 |
| 2. 人口上限政策 | 北京<2300万、上海<2500万（2020年目标）→ 限制新开发 |
| 3. 一线城市补偿成本更高 | 征地补偿→一线城市地价更高→开发商不愿拿地 |
| 4. 政治经济学 | 已开发土地利益者（在超级城市更强大）→ 限制新供给 |
| 5. 腐败 | Hsu et al. (2017)：腐败影响土地供给决策 |

**Yu (2024) 补充解释**：
- 超级城市对土地出让金收入的依赖更低
- 更有动力限制高密度开发（以限制负外部性）

### 2.3 假说三：性别比与婚姻市场（Wei & Zhang 2011）

**背景**：中国由于历史上的生育政策，出生性别比失调，20-29岁男多女少

**机制**：
- 传统文化：男性需要拥有房产才能在婚姻市场有吸引力
- 竞争激烈 → "六个钱包"（父母+祖父母双方）共同出资购房
- 高性别比地区 → 更高的住房需求

**实证发现（Wei & Zhang 2011）**：
- **性别比每增加10个百分点 → 本地住房成本上涨4%**

```
性别比失衡 → 婚姻市场竞争↑ → 男性购房动力↑↑
            → 六钱包效应 → 需求大幅增加
```

### 2.4 假说四：城市便利设施与制度因素

**主要因素**：
1. 优质教育/医疗资源集中在超级城市
2. 户籍（Hukou）制度限制公共服务获取
3. 高储蓄率被迫转向住房（实际存款利率接近零）
4. 传统产权偏好（中国文化中对"自己的房子"的强烈渴望）

**Chan et al. (2020)**：
- 顶尖学区（"超级学校"）房价高出**14%**（约43万元人民币）

## 三、土地财政体系

**1994年分税制改革**创造了地方政府对土地出让金的高度依赖：

```
中央政府获得大部分税收（如增值税75%）
    ↓
地方政府财力不足，但有大量支出责任
    ↓
解决方案：土地出让金（一次性卖地收益）成为地方主要收入
    ↓
激励：地方政府 = 开发的最大推动者
    ↓
高地价 → 开发商高价拿地 → 高房价（成本转嫁购房者）
```

**土地财政的特征**：
- 地方政府对土地相关支出有高度自主权
- 强烈激励推动本地经济发展
- 创造了财政联邦主义动态

## 四、中国土地使用法规

**中国规划系统**：地块层面设计（Parcel-Level Design）

- 用途类型（住宅/商业/工业）
- 容积率（FAR）限制
- 密度限制
- 高度限制

不同于区划（美国）或开发控制（英国）

**特点**：城市间差异巨大，且往往与超级城市的高需求"反向"（FAR限制更严格）

## 五、政策干预与评估

### 5.1 购房限制（Purchase Restrictions）

**政策**：限制非本地户籍、已有多套房者购买住房

**结果**：
- 减少非自住购买约**40%**
- 效果随时间衰减（绕过方式出现）
- **对价格无显著影响**（原因：价格向下粘性，损失厌恶，卖家不愿降价）

### 5.2 房产税试点

| 城市 | 税率 | 结果 |
|------|------|------|
| 上海 | 0.4-0.6% | 房价下降**11-15%** |
| 重庆 | 0.5-1.2% | 高端市场重庆-10%，但低端市场+10-12%（溢出效应）|
| Lyu (2024) | — | 税率更高的房屋多降**2.73%** |

### 5.3 销售限制（Sales Restrictions）

**政策**：禁止转售（如新建商品房5年内不得出售）

**目的**：限制投机行为

**效果**：减少交易量，但无法根本解决可及性问题

### 5.4 保障性住房

- 公共租赁住房（Public Rental Housing）
- 共有产权住房（Shared Ownership）
- 规模有限，远不足以覆盖需求

## 六、政策挑战与评估

**关键问题**：
1. 购买限制能否长期解决可及性？（Somerville et al. 2020：否，仅减少交易量）
2. 对年轻首次购房者的影响？对内部流动性的影响？
3. 房产税设计：应征哪些房产？税率？如何再分配？

**核心问题**：中国的可及性危机根本上是**供给问题**（类似英国），但解决供给约束面临强大的政治经济学阻力。

