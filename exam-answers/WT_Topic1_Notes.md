## 一、Tiebout模型（1956）

### 1.1 核心思想："用脚投票"（Vote with your feet）

**背景**：公共品应该由谁提供？多少？

**Tiebout的答案**：人口流动 + 辖区竞争 = 有效提供地方公共品

**机制**：
```
不同辖区提供不同的公共品组合+税率
    ↓
居民按偏好"购买"辖区
    ↓
竞争迫使辖区提供最优组合
    ↓
效率达到（类似私人市场效率）
```

### 1.2 Tiebout模型的关键假设

| 假设 | 内容 |
|------|------|
| 完全信息 | 居民了解所有辖区的服务和税收 |
| 无成本流动 | 搬迁无摩擦成本 |
| 大量辖区 | 足够多的辖区供选择 |
| 无溢出效应 | 一个辖区的公共品不影响邻近辖区 |
| 无规模经济 | 小辖区与大辖区提供公共品的成本相同 |

**现实局限**：
- 搬迁有成本（住房成本、社会网络断裂）
- 辖区数量有限
- 存在溢出效应（如教育对邻近辖区的正外部性）

### 1.3 Tiebout假说的检验

**若Tiebout有效**：
- 财政变量（税收、学校质量）被资本化进房价
- 相同辖区内同质家庭聚居（阶层/收入同质化）
- 服务水平接近居民偏好

**实证方法**：特征价格法（hedonic model）

## 二、房价资本化（Capitalization）

### 2.1 基本逻辑

**Oates (1969) — 地方财政与房价的先驱研究**

逻辑：若某邻里的学校质量提高 → 需求增加 → 价格上涨

**资本化公式**：

房价 = Σ（未来服务流量的现值）= R / r

→ 任何增加"服务流量"的变量（如学校质量↑）都会提高房价

### 2.2 Oates (1969) 主要发现

- 财产税增加 £1000 → 房价下降 **£664**（约67%资本化）
- 学校支出增加 → 房价上涨（正向资本化）

### 2.3 学校质量与房价

文献中的估计范围：**学校质量提升1个标准差 → 房价提升1.3%-10%**

| 研究 | 发现 |
|------|------|
| Gibbons et al. (2013) | 英国：学校质量显著正向影响房价 |
| Cheshire & Sheppard (2004) | 英国：优质学区有实质性价格溢价 |

### 2.4 Hilber et al. (2011) — 中央政府补贴的资本化

**关键发现**：中央政府补贴**大部分甚至完全**被资本化进房价

**供给约束的调节作用**（关键！）：
- 有物理障碍（建设受限）的地区：资本化程度**更高**
- 供给弹性强的地区：资本化程度低

```
供给约束 → 供给无弹性 → 补贴→价格↑（而非数量↑）
                              ↓
                         房主获益，租户不受益
```

**税收资本化弹性**：约0.3（税收增加10% → 租金/价格下降3%）≈ 50%资本化率

## 三、政策含义

### 3.1 谁从政府补贴中获益？

**关键洞见**：政府补贴（财政援助、学校改善）**主要惠及现有房主（homeowners）和房东（landlords）**，而非租户（renters）。

原因：补贴 → 需求↑ → 在供给受限的情况下 → 价格↑ → 只有拥有资产的人获益

```
补贴效应：
  弹性供给地区（新建容易）：
    → 价格小幅↑，数量大幅↑ → 租户受益（更多住房选择）
  
  非弹性供给地区（新建受限）：
    → 价格大幅↑，数量小幅↑ → 房主受益，租户受损（更高租金）
```

### 3.2 资本化的激励效应

**有利的一面**：资本化创造了良好的激励效应
- 投资改善学校 → 提升当地房价 → 激励现有房主支持教育投资
- 形成"房主投票"（homevoter）效应（Fischel 2000）

### 3.3 政策建议

1. **不要帮助地点（places），要帮助人（people）**（Hilber & Turner）
2. 若目标是帮助租户/低收入家庭，直接补贴更有效（避免资本化损失）
3. 改善地方公共品前，需考虑谁拥有该地区的住房

## 四、Tiebout与房地产市场

### 4.1 Tiebout模型对房地产的核心含义

```
辖区分化（学校质量、税率、犯罪率差异）
    ↓
房价反映辖区吸引力的差异
    ↓
特征价格法可以估算各种辖区特征的隐含价格
    ↓
政策变化（如学校区重划）→ 预测房价变化
```

### 4.2 同质化与分层

Tiebout机制 → 相似偏好的人聚居 → 收入/阶层同质化的社区

这与AT Topic 8（隔离）形成呼应：Tiebout过程是收入隔离的经济机制之一。

## 五、考试要点

### 核心数字

| 数字 | 来源 | 含义 |
|------|------|------|
| **£664/£1000** | Oates (1969) | 税收增加£1000的资本化进房价的金额 |
| **1.3%-10%** | 文献范围 | 学校质量1标准差改善的房价提升 |
| **~50%** | Hilber et al. | 平均税收资本化率（弹性0.3） |
| **更高资本化** | Hilber et al. (2011) | 供给受限地区补贴资本化更多 |

### Tiebout速查

```
核心：用脚投票 → 辖区竞争 → 有效提供公共品
关键假设：完全信息、无成本流动、大量辖区
实证检验：财政变量→房价资本化
政策含义：补贴→主要惠及房主（非租户）
```
