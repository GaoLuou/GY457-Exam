## 一、密度的经济效应

### 1.1 如何测量城市？

两种划定城市空间的方法：
| 方法 | 定义 | 优点 |
|------|------|------|
| **功能方法** (Functional) | 基于通勤流（commuting flows） | 捕捉劳动力市场范围 |
| **形态方法** (Morphological) | 基于连续建成区（built-up space） | 捕捉物理城市范围 |

无绝对优劣，取决于研究问题。

### 1.2 密度的收益 (Benefits of Density)

#### (i) 生产率收益
- **密度弹性 = 0.04**（Ahlfeldt & Pietrostefani 2019 元分析）
- 密集城市生产率更高——但存在选择性偏差（能力高的工人向大城市迁移）

#### (ii) 可及性收益
- 更高密度→期望距离更短
- **但**：也鼓励更多出行，抵消部分好处
  - Duranton & Turner (2018)：出行距离对密度的弹性 = **-0.13**（美国）
- 商品多样性随密度增加（Handbury & Weinstein 2015）

#### (iii) 其他收益
- 更多创新活动（知识溢出）
- 更低人均温室气体排放（因出行减少、住宅面积缩小）
- 内生性便利设施（高技能居民→更低犯罪、更多消费机会）

### 1.3 密度的成本 (Costs of Density)

#### (i) 土地稀缺与住房成本
- 更高密度 → 土地稀缺 → 住房更贵
- 注意：土地价格上涨是**转移**（transfer），不完全是经济损失
- 但也反映社会成本（更少空间消费）
- 激励开发者建造更高楼（好：更多建筑面积；坏：边际成本随高度增加）

#### (ii) 拥堵与通勤成本
- 城市扩张 → 行驶速度下降
  - **弹性：城市人口↑1% → 行驶速度↓0.04%**（美国，Duranton & Puga 2023）
  - 印度：**-0.05%**（Akbar et al. 2019）
- 房价与通勤成本的trade-off是单中心城市模型的核心

#### (iii) 负便利设施
- 犯罪率更高
- 污染与健康问题
- 历史上：19世纪初农村青年比城市青年**多活8-12年**（Bairoch 1988）
- 欧洲/北美：城市预期寿命到**1930年代**才超过农村

## 二、均衡城市规模

### 2.1 成本收益的净效应：倒U形

```
净效益/工人
   |
   |          ●●●
   |       ●●    ●●
   |      ●        ●   ← 最优规模（倒U形顶点）
   |    ●            ●
   |  ●                ●
   |●                    ●
   |_______________________
   0    小    中    大    城市人口N

收益增速 > 成本增速：城市扩大有利
成本增速 > 收益增速：城市过大有害
```

**问题**：倒U形顶点相当**平坦**——略微偏离最优规模代价较小。

### 2.2 迁移与均衡城市规模

迁移机制：价格调整确保空间均衡
- 城市停止增长（当租金过高）
- 问题：市场均衡是否有效？

**城市往往太大！**

原因：
```
效用/工人
   |     收益曲线（橙色）
   |    /
   |   /       净效用（蓝色）
   |  /       ●●●●●
   | /      ●●    ●●
   |       ●        ● ← 最优N*
   |______________________
   |   城市规模N
   均衡：效用=u*（大于最优处）
   → 迁移不在最优点停止，而在u=u*处停止
```

在均衡中，所有城市的效用相等（u*），但所有城市都超过最优规模。

### 2.3 市场失灵与政策

**三种失灵**：

| 失灵类型 | 方向 | 解释 |
|----------|------|------|
| a. 集聚外部性：只享受别人的，不考虑自己给别人的 | 密度**过低** | 公共品搭便车 |
| b. 居民不内化拥堵成本 | 密度**过高** | 额外的拥堵是负外部性 |
| c. 土地非本地居民所有，集聚收益以租金流出 | 密度**过低** | 收益不归居民 |

**政策**：
- 土地使用法规（限制住房供给）— 冬季学期详细讲
- 改善城市基础设施（减少拥堵）
- 吸引高本地化经济效应的行业

### 2.4 城市有多大才合适？

**悖论**：
- 均衡城市往往太大（从本地成本-收益看）
- 但更密集的城市似乎提升福利

**解决**：成本和收益由不同群体承担！
- 迁移决策基于**本地**成本
- 但密度有**全国/全球**收益（更有效的公共品供给、更低碳排放）
- → 考虑全球外部性时，城市可能**太小**（Borck & Tabuchi 2018）

## 三、补偿性差异：Rosen-Roback框架

### 3.1 基本逻辑

**空间均衡条件**：自由流动的人口意味着各地效用相等。

→ 租金和工资**内生调整**以补偿不同地点的吸引力差异。

### 3.2 模型设置

- 两个城市 j=1,2
- 两种商品：可贸易复合品Q + 不可贸易土地H
- 生产率（和效用）A_j 在各城市外生差异
- 企业和工人可自由流动
- 工资w和租金p调整以清市
- **均衡条件**：效用相等 AND 利润相等（完全竞争）

### 3.3 企业均衡

企业利润 π = Q_j - pH - wL = 0（竞争 → 零利润）

**关键**：在所有城市，每单位Q的成本相同：C(p₁,w₁) = C(p₂,w₂) = 1

→ 若p（租金）↑，则w（工资）必须↓（企业在一个要素上多花钱，必须在另一个上省钱）

### 3.4 工人均衡

工人效用 U = U(a_j, q, h)，受预算约束：w_j = q + p·h

均衡：各城市效用相等 V(p₁,w₁) = V(p₂,w₂)

→ 若p（租金）↑，则w（工资）必须↑（工人需要更高工资才愿意留下）

### 3.5 均衡图解

```
        w（工资）
        |         零利润线C=0
        |        /（斜率为负：p↑→w↓）
        |       /
    w₁  |------●  ← 均衡点
        |     / \
        |    /   \
        |   /     零效用线V=V̄
        |  /      /（斜率为正：p↑→w↑）
        |_/______________________
                p（租金）
```

### 3.6 关键预测（必背！）

| 冲击类型 | 租金变化 | 工资变化 | 直觉 |
|----------|----------|----------|------|
| **生产性便利设施↑** (A↑) | ↑ | ↑ | 企业愿意支付更多 → 工人需更高工资维持效用 |
| **居住便利设施↑** (a↑) | ↑ | ↓ | 居民接受更低工资 → 竞相出价推高租金 → 企业降工资维持利润 |
| **两者都↑** (A↑,a↑) | ↑↑ | 不确定 | 两种力量对工资方向相反 |

```
生产性便利设施↑（如政府补贴）：
  → 企业生产率↑ → 企业能支付更高租金和工资
  → 工人涌入 → 租金和工资均上升

居住便利设施↑（如风景秀丽）：
  → 居民愿意接受更低工资（补偿）
  → 居民竞相出价 → 租金↑
  → 企业必须降低工资维持零利润
  → 最终：租金↑，工资↓
```

### 3.7 英国证据 (Gibbons et al., 2011)

顶级地区（如伦敦、布莱顿）：**更高租金 + 更低工资**
- 说明这些地区的**居住便利设施**起主导作用

便利设施（工资相对低的地方）：就业可及性、林地、博物馆、坡度
负便利设施（工资相对高的地方）：降雨量、颗粒物、犯罪率

### 3.8 密度是便利设施吗？

- 密度↑工资↑ → 必须是**生产性**便利设施
- 密度↑租金↑幅度大于工资↑ → 必须也是**居住性**便利设施
- 密度-生活质量关系呈倒U形 → 极高密度和极低密度都不受欢迎

## 四、考试要点

### 关键数字总结

| 数字 | 来源 | 含义 |
|------|------|------|
| **0.04** | Ahlfeldt & Pietrostefani (2019) | 密度弹性（生产率） |
| **-0.13** | Duranton & Turner (2018) | 出行距离对密度的弹性 |
| **-0.04** | Duranton & Puga (2023) | 行驶速度对城市人口的弹性（美国） |
| **8-12年** | Bairoch (1988) | 19世纪初农村vs城市预期寿命差距 |
| **1930s** | — | 欧美城市预期寿命超越农村的年代 |

### Rosen-Roback速查

```
生产性便利设施↑ → 租金↑，工资↑
居住性便利设施↑ → 租金↑，工资↓
两种均↑       → 租金↑↑，工资方向不确定
```

### 可能考题

**Essay型**：
- "Evaluate the costs and benefits of high urban density. Is there an optimal city size?"
- 答题：收益（生产率0.04、可及性）→ 成本（土地稀缺、拥堵-0.04弹性、历史死亡率）→ 倒U形 → 均衡太大（三种失灵）→ 全球vs本地外部性

**Partitioned型**：
- (a) 解释Rosen-Roback框架。当一个城市的居住便利设施改善时，工资和租金如何变化？
- (b) 为什么均衡城市规模往往过大？存在哪些市场失灵？
- (c) 为什么更大、更密集的城市在均衡上往往太大，但又看似提升福利？
